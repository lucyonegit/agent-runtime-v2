# 执行器上下文闭环重构 Implementation Plan

> 状态：Implemented（2026-07-12）。下方 checkbox 保留原始执行拆分与命令记录；实际落地结果以第 08 篇和当前源码为准。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改变数据库写入、Plan/Step/ReAct/HITL 执行链和对外协议的前提下，把 Context 业务选择归还给 Direct/Plan/Step 所有者，将 ContextBuilder 收敛为纯 ContextCompiler，并提供只读 ContextInspectionService。

**Architecture:** `RuntimeJobExecutionService` 保留 lease、heartbeat、route 和 dispatch；Direct/Plan/Step 执行器只包装当前调用顺序。执行器通过只读 ContextLoader 产生 `ContextMaterial`，现有 AgentRunner/StepRunner 在调用 AgentLoop 前由 ReAct 边界编译一次；AgentLoop 内继续使用局部 LangChain Messages。ContextInspectionService 复用相同 Loader，但永远不写库。

**Tech Stack:** TypeScript 5、Node.js ESM、LangChain `@langchain/core`、NestJS、PostgreSQL、Vitest。
