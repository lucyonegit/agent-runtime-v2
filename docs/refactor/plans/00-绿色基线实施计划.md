> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复当前后端语法损坏，建立可重复启动的 PostgreSQL 测试环境，并为 Job + StepRun 重构打下后端、数据库和 Web 都可验证的绿色 Git 基线。

**Tech Stack:** TypeScript、Vitest、PostgreSQL 16、Docker Compose、Bash、React/Vite。

```ts
  private async appendToolAnswer(
    sessionId: string,
    request: AgentInputRequest,
    value: unknown,
    messageId: string,
    taskId: string
  ): Promise<AgentMessage> {
    if (!request.toolCallId || !request.toolName) {
      throw new Error(`Input request ${request.id} is missing tool call metadata`);
    }

    return this.config.store.appendMessage({
      id: messageId,
      sessionId,
      taskId,
      role: 'tool',
      content: this.stringifyAnswer(value),
      toolResult: {
        toolCallId: request.toolCallId,
        toolName: request.toolName,
        status: 'completed',
        result: value,
      },
      createdAt: this.now(),
      metadata: { inputRequestId: request.id },
    });
  }
```

- [ ] **Step 2: Add the isolated PostgreSQL 16 Compose service**

Create `compose.postgres-test.yml`:

```yaml
services:
  postgres-test:
    image: postgres:16-alpine
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: postgres
      POSTGRES_DB: agent_runtime_test
    ports:
      - "127.0.0.1:55433:5432"
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U postgres -d agent_runtime_test"]
      interval: 1s
      timeout: 3s
      retries: 30
    tmpfs:
      - /var/lib/postgresql/data
```

The test service deliberately uses port `55433`, not the old implicit `5433`, to reduce collision with a developer PostgreSQL instance.

- [ ] **Step 3: Add the cleanup-safe PostgreSQL test runner**

Create `scripts/test-postgres.sh`:

```bash
#!/usr/bin/env bash
set -euo pipefail

ROOT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
COMPOSE_FILE="$ROOT_DIR/compose.postgres-test.yml"
DATABASE_URL="postgresql://postgres:postgres@127.0.0.1:55433/agent_runtime_test"

cleanup() {
  docker compose -f "$COMPOSE_FILE" down --volumes --remove-orphans
}

trap cleanup EXIT INT TERM

docker compose -f "$COMPOSE_FILE" up --detach --wait

cd "$ROOT_DIR"
DATABASE_URL="$DATABASE_URL" \
  ./node_modules/.bin/vitest run --exclude 'dist/**' tests/postgres-store.test.ts
```

Make it executable:


```ts
    if (pool) {
```
